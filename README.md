## Description

KubitCharts iOS library that contains chart components based on Kubit Design System created by the UX/UI Team on ODS.
The chart components contained in this library help to develop scalable and configurable Charts of different types with the given data that is passed into them.

This repository contains following libraries:

* KubitCharts
* GSStorybook

It also includes global storybook sample application, used mainly for testing and quality purposes.

## Requirements

0. Required software:

    * Xcode 16 or newer (16.4 recommended)
    * Java (for running maven)
    * Homebrew (https://brew.sh/)
    * Ruby 3.2.6 (required by fastlane)

## Previews
To see examples of how to initialize and use each Chart component provided by this library, please refer to the corresponding Preview files.
